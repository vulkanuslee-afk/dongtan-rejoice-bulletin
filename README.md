# 동탄즐거운교회 웹 주보 (초안)

종이 주보를 그대로 휴대폰으로 옮긴 **웹 주보**입니다.
**2026년 11월 8일 45호** 주보 내용이 실제로 들어가 있습니다.

앱스토어 설치·심사가 없고, 카톡 링크 하나로 열립니다. 홈 화면에 추가하면 앱처럼 보입니다.

> 지금 교회 홈페이지(rejoicech.kr)에는 주보가 **스캔 이미지**로 올라갑니다.
> 폰에서 확대해야 읽히고, 글자를 복사할 수도 검색할 수도 없습니다.
> 이 앱은 같은 내용을 **폰에서 바로 읽히는 형태**로 바꾼 것입니다.

---

## 탭 구성

| 탭 | 내용 | 종이 주보의 어디 |
|---|---|---|
| **주보** | 표어·설교·예배 안내·공동체 모임·오시는 길 | 1면 + 예배 안내 |
| **순서** | 예배 순서 + **설교 노트**(직접 입력, 자동 저장) | 예배 순서면 |
| **챌린지** | 말씀 구절 · 4단계(말씀/묵상/기도/실천) · **요일 체크** · 묵상 답변 | 일상예배 챌린지 |
| **소식** | 공동체 소식 · 이번 주 일정 · (신청 받을 때 신청 카드) | 공동체 소식 |
| **섬김** | 헌금 계좌(복사) · 즐거운재가노인요양센터 · 후원 선교사 | 하단 + 부설기관 |
| **비전** | 슬로처치 · 핵심가치 · 신앙고백 | 비전 선언문 |

### 종이로는 못 하던 것

- **설교 노트** — 주보의 빈칸이 실제로 써지고, 폰에 남습니다
- **일상예배 체크** — 월~주일 중 실천한 날을 눌러 표시, "이번 주 N일 실천"
- **묵상 질문 답변** — 한 문장 답을 적어두고 다음 주에 다시 봅니다
- **계좌·주소 복사**, 카카오맵·티맵 길찾기, 전화 바로 걸기

일상예배 챌린지는 주일에 읽고 끝나는 게 아니라 한 주 내내 쓰는 것이라,
종이보다 폰이 훨씬 맞는 기능입니다. 이 앱의 중심을 여기에 뒀습니다.

## 1. 매주 하는 일 (3분)

`data/bulletins.js` 를 열고, `list: [` 바로 아래에 이번 주 블록을 **복사해 붙여넣고 내용만 바꿉니다.**

```js
{
  date: "2026-11-15",
  issue: "46호",
  label: "추수감사주일",
  theme: "설교 제목",
  sermon: { title: "설교 제목", text: "골로새서 3:15-17", preacher: "김경환 목사", youtube: "" },
  order: [
    { part: "묵상의 시간", by: "다 같 이" },
    { part: "찬양",       by: "다 같 이", note: "찬양 제목 · 찬양 제목" },
    { part: "말씀 나눔",  by: "김경환 목사", bible: "골로새서 3:15-17", note: "설교 제목" }
  ],
  memoPrompt: "설교에서 마음에 남는 표현을 적고 ...",
  challenge: {
    verseRef: "골로새서 3:15",
    verse: "그리스도의 평강이 ...",
    steps: [ { k:"말씀", v:"성경 한 구절 천천히 읽어보기" }, ... ],
    question: "묵상 질문",
    task: "이번 주 실천 과제",
    note: "추가 묵상질문은 유튜브 영상 참고"
  },
  notices: [ { title: "제목", body: "내용" } ],
  calendar: [ { when: "11/19(수)", what: "수요예배" } ],
  picks: null            // 신청 받을 때만 채우기
}
```

저장하고 GitHub에 올리면 끝입니다. 교인들이 보던 링크 그대로 새 주보가 뜹니다.
**앱이 아니라 웹이라 "업데이트 기다리기"가 없습니다.**

교회 기본 정보(주소·계좌·예배시간·비전)는 `church` 블록에 있고, 바뀔 때만 고치면 됩니다.

## 2. 배포 (처음 한 번만)

1. GitHub에서 저장소 만들기 (예: `rejoice-bulletin`)
2. 이 폴더의 파일 전부 올리기
3. Settings → Pages → Source: `main` / `root` 저장
4. 2~3분 뒤 `https://아이디.github.io/rejoice-bulletin/` 으로 열립니다
5. 주소를 교회 단톡방에 공지 (홈페이지 주보 게시판에도 링크)

고친 내용이 바로 안 보이면 뒤에 `?v=2`, `?v=3` 을 붙여 공유하면 확실합니다.

## 4. 개인정보 — 지난주 헌금 명단

종이 주보에는 **지난주 헌금 명단(실명 15명)** 이 실려 있지만, 이 앱에는 **넣지 않았습니다.**

공개 웹주소는 검색엔진에 잡힐 수 있고, 누가 얼마를 드렸는지와 연결되는 정보라
교회 밖으로 나가면 되돌릴 수 없습니다. 담임목사님 휴대전화도 같은 성격입니다.

넣으시려면 둘 중 하나를 권합니다.

1. 명단 페이지만 **별도 비공개 주소**로 분리 (링크를 아는 사람만 접근)
2. 간단한 암호 입력 후 보이게 처리

`data/bulletins.js` 의 `offeringNames` 자리가 그 용도로 비워져 있습니다.

분량을 늘리실 계획이면(예: 본문 전체 게재) 성서공회 사용 허락 범위를 먼저 확인해 주세요.

## 6. 다음 단계 (필요할 때)

### (가) 사무실에서 엑셀처럼 고치기 — 구글 스프레드시트 연동
주보 내용을 **구글 시트 한 장**에 적고 앱이 읽어오게 바꿀 수 있습니다.
그러면 매주 작업이 "시트에 타이핑"으로 끝나고, 코드 파일은 열 일이 없습니다.

### (나) 신청 인원 자동 집계 — Google Apps Script
지금 **신청** 기능은 각자 폰에 저장 + "복사해서 카톡 전송" 방식입니다.
전체 인원을 자동으로 모으려면 **Apps Script + 스프레드시트**가 가장 현실적입니다.
(무료, 교회 구글 계정만 있으면 되고, 결과를 사무실에서 시트로 바로 확인)

### (다) 설교 영상 연결
`sermon.youtube` 에 주소를 넣으면 주보에서 바로 설교 영상으로 갑니다.
챌린지의 "추가 묵상질문 유튜브 영상"도 같은 방식으로 붙일 수 있습니다.

### (라) 행사 페이지
수련회·나들이 때는 좌석표·타임테이블·장소 길찾기·사진첩을 붙인 행사 페이지를
따로 만들어 주보에서 링크로 연결하는 방식이 깔끔합니다.

## 파일 구조

```
교회주보앱/
├─ index.html                 앱 전체 (화면 + 동작)
├─ data/
│  ├─ bulletins.js            ← 매주 고치는 파일
│  └─ hymns.js                찬송가 번호 → 제목 (쓸 때만)
├─ manifest.webmanifest       홈 화면 추가용
├─ sw.js                      오프라인 캐시 (주보 데이터는 항상 새로 받음)
├─ icon.svg                   아이콘
└─ README.md                  이 문서
```
