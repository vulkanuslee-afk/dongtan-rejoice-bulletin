종이 주보를 그대로 휴대폰으로 옮긴 **웹 주보**입니다.

저장소: https://github.com/vulkanuslee-afk/dongtan-rejoice-bulletin

앱스토어 설치·심사가 없고, 카톡 링크 하나로 열립니다. 홈 화면에 추가하면 앱처럼 보입니다.

> 지금 교회 홈페이지(rejoicech.kr)에는 주보가 **스캔 이미지**로 올라갑니다.

> 이 앱은 같은 내용을 **폰에서 바로 읽히는 형태**로 바꾼 것입니다.

## 탭 구성

| 탭 | 내용 | 종이 주보의 어디 |
|---|---|---|
| **주보** | 표어·설교·예배 안내·공동체 모임·오시는 길 | 1면 + 예배 안내 |
| **순서** | 예배 순서 + **설교 노트**(직접 입력, 자동 저장) | 예배 순서면 |
| **챌린지** | 말씀 구절 · 4단계(말씀/묵상/기도/실천) · **요일 체크** · 묵상 답변 | 일상예배 챌린지 |
| **소식** | 공동체 소식 · 이번 주 일정 · (신청 받을 때 신청 카드) | 공동체 소식 |
| **섬김** | 헌금 계좌(복사) · 즐거운재가노인요양센터 · 후원 선교사 | 하단 + 부설기관 |
| **비전** | 슬로처치 · 핵심가치 · 신앙고백 | 비전 선언문 |

### 종이로는 못 하던 것

- **설교 노트** — 주보의 빈칸이 실제로 써지고, 폰에 남습니다
- **일상예배 체크** — 월~주일 중 실천한 날을 눌러 표시, "이번 주 N일 실천"
- **묵상 질문 답변** — 한 문장 답을 적어두고 다음 주에 다시 봅니다
- **나눔 · 기도 제목** — 교인이 적어서 목사님께 문자/카톡으로 바로 전송
- **식사·행사 선택** — 이름 + 선택을 눌러 문자/카톡으로 전송
- **계좌·주소 복사**, 카카오맵·티맵 길찾기, 전화 바로 걸기

## 1. 매주 하는 일 — 더블클릭 두 번

주보 담당자가 **워드 파일(.docx)** 을 주면:

1. 워드 파일을 **`1_주보변환.bat` 아이콘 위로 끌어다 놓기**
   → 날짜 · 호수 · 절기 · 설교 제목 · 성경 본문 · 예배 순서 · 공동체 소식 · 일정을
     알아서 뽑아 `data/bulletins.js` 맨 위에 넣고, 미리보기를 엽니다
2. 확인했으면 **`2_올리기.bat` 더블클릭** → 메모 적고 엔터

2~3분 뒤 교인들 폰에서 새 주보가 보입니다.

변환이 못 찾은 항목은 **지어내지 않고** `TODO: 확인` 으로 남기고, 무엇을 못 찾았는지
화면에 알려줍니다. `data/bulletins.js` 에서 그 부분만 고치면 됩니다.
고치기 전 상태는 `data/bulletins.backup.js` 에 자동 백업됩니다.

| 파일 | 하는 일 |
|---|---|
| `1_주보변환.bat` | 워드 → 주보 데이터 (끌어다 놓기) |
| `2_올리기.bat` | 깃허브에 올리기 |
| `0_미리보기.bat` | 올리기 전에 확인만 |

깃허브 쓰는 법은 **[docs/깃허브-올리는법.md](docs/깃허브-올리는법.md)** 에 처음부터 적어 뒀습니다.

### 직접 고칠 때

`data/bulletins.js` 를 열고, `list: [` 바로 아래에 이번 주 블록을 **복사해 붙여넣고 내용만 바꿉니다.**

```js
{
  date: "2026-11-15",
  issue: "46호",
  label: "추수감사주일",
  theme: "설교 제목",
  sermon: { title: "설교 제목", text: "골로새서 3:15-17", preacher: "김경환 목사", youtube: "" },
  order: [
    { part: "묵상의 시간", by: "다 같 이" },
    { part: "찬양",       by: "다 같 이", note: "찬양 제목 · 찬양 제목" },
    { part: "말씀 나눔",  by: "김경환 목사", bible: "골로새서 3:15-17", note: "설교 제목" }
  ],
  memoPrompt: "설교에서 마음에 남는 표현을 적고 ...",
  challenge: {
    verseRef: "골로새서 3:15",
    verse: "그리스도의 평강이 ...",
    steps: [ { k:"말씀", v:"성경 한 구절 천천히 읽어보기" }, ... ],
    question: "묵상 질문",
    task: "이번 주 실천 과제",
    note: "추가 묵상질문은 유튜브 영상 참고"
  },
  notices: [ { title: "제목", body: "내용" } ],
  calendar: [ { when: "11/19(수)", what: "수요예배" } ],
  picks: null            // 신청 받을 때만 채우기
}
```

저장하고 GitHub에 올리면 끝입니다. 교인들이 보던 링크 그대로 새 주보가 뜹니다.
**앱이 아니라 웹이라 "업데이트 기다리기"가 없습니다.**

교회 기본 정보(주소·계좌·예배시간·비전)는 `church` 블록에 있고, 바뀔 때만 고치면 됩니다.

## 2. 공개 배포 (처음 한 번만)

로컬 커밋까지는 끝나 있습니다. 아래 두 줄이면 공개 주소가 생깁니다.

```bash
gh repo create dongtan-rejoice-bulletin --public --source . --push
gh api -X POST repos/vulkanuslee-afk/dongtan-rejoice-bulletin/pages -f "source[branch]=main" -f "source[path]=/"
```

2~3분 뒤 주소: `https://vulkanuslee-afk.github.io/dongtan-rejoice-bulletin/`

이후 주보를 고칠 때는:

```bash
git add -A && git commit -m "11월 15일 46호" && git push
```

고친 내용이 바로 안 보이면 주소 뒤에 `?v=2`, `?v=3` 을 붙여 공유하면 확실합니다.

### 공개 범위

누구나 주소만 알면 볼 수 있는 **공개 페이지**입니다. 다만 `<meta name="robots" content="noindex">`
를 넣어 **검색에는 안 잡히게** 해 뒀습니다. 교인들은 링크로 들어오고, 모르는 사람이 검색으로
흘러들어올 일은 없습니다.

공개되는 것: 예배시간 · 예배순서 · 설교 제목 · 공동체 소식 · 교회 주소/전화 · 헌금 계좌 · 비전
공개 안 되는 것: 지난주 헌금 명단(실명) — 아래 4번 참고

내려야 할 일이 생기면 저장소 Settings → Pages에서 끄거나 저장소를 비공개로 바꾸면 즉시 닫힙니다.

## 4. 개인정보 — 지난주 헌금 명단

종이 주보에는 **지난주 헌금 명단(실명 15명)** 이 실려 있지만, 이 앱에는 **넣지 않았습니다.**

공개 웹주소는 검색엔진에 잡힐 수 있고, 누가 얼마를 드렸는지와 연결되는 정보라
교회 밖으로 나가면 되돌릴 수 없습니다. 담임목사님 휴대전화도 같은 성격입니다.

넣으시려면 둘 중 하나를 권합니다.

1. 명단 페이지만 **별도 비공개 주소**로 분리 (링크를 아는 사람만 접근)
2. 간단한 암호 입력 후 보이게 처리

`data/bulletins.js` 의 `offeringNames` 자리가 그 용도로 비워져 있습니다.

## 5. 성경 본문 — 장절만 적으면 본문이 나옵니다

예배순서나 설교의 **본문 보기**를 누르면 성경 본문이 앱 안에서 바로 펼쳐집니다.
링크로 나가지 않습니다.

`data/bible/` 에 **개역한글 66권**이 책별 파일로 들어 있습니다. 본문을 볼 때
그 책 파일 하나만 내려받으므로(골로새서 5KB, 시편 400KB) 첫 화면은 그대로 빠릅니다.

주보에 `bible: "골로새서 3:15-17"` 처럼 장절만 적으면 끝입니다. 이런 표기를 다 알아봅니다.

```
골로새서 3:15-17      요한복음 3:16       시편 23 (장 전체)
살전 5:16-18 (약칭)    창 1:1-3            골로새서 3:15-4:1 (장 넘김)
```

### 번역본 — 읽어 주세요

들어 있는 본문은 **개역한글**입니다. 교회가 쓰시는 **개역개정과 표현이 조금 다릅니다.**
같은 골로새서 3:15만 봐도:

- 개역개정 … 너희는 평강을 위하여 한 몸으로 부르심을 받았나니 **너희는** 또한 감사하는 자가 되라
- 개역한글 … 평강을 위하여 **너희가** 한 몸으로 부르심을 받았나니 또한 **너희는** 감사하는 자가 되라

개역개정 전문은 공개 배포되는 데이터가 없어 자동으로 채울 수 없습니다.
그 주 본문만 개역개정으로 맞추고 싶으시면 `data/bulletins.js` 맨 위
`passages` 에 붙여넣으세요. **여기 있는 본문이 자동 본문보다 우선합니다.**

```js
passages: {
  "골로새서 3:15-17": "15 그리스도의 평강이 ...\n16 ...\n17 ..."
},
```

붙여넣은 본문에는 `주보 본문`, 자동 본문에는 `개역한글` 꼬리표가 붙어
교인들이 어느 번역을 보고 있는지 헷갈리지 않습니다.

### 찬송가·CCM

찬송가 가사와 복음성가 가사는 아직 안 넣었습니다(번호·제목만). 넣으시려면
`data/hymns.js` 의 각 항목에 가사를 적으면 바로 표시됩니다.

> 참고 — 개역개정은 대한성서공회, 새찬송가 가사는 한국찬송가공회 저작물입니다.
> 교인 20여 명이 보는 교회 내부용이라는 판단은 존중하되, 나중에 공개 범위가
> 넓어지면 한 번 확인해 두시는 게 좋습니다.

## 6. 다음 단계 (필요할 때)

### (가) 사무실에서 엑셀처럼 고치기 — 구글 스프레드시트 연동
주보 내용을 **구글 시트 한 장**에 적고 앱이 읽어오게 바꿀 수 있습니다.
그러면 매주 작업이 "시트에 타이핑"으로 끝나고, 코드 파일은 열 일이 없습니다.

### (나) 신청 인원 자동 집계 — Google Apps Script
지금 **신청** 기능은 각자 폰에 저장 + "복사해서 카톡 전송" 방식입니다.
전체 인원을 자동으로 모으려면 **Apps Script + 스프레드시트**가 가장 현실적입니다.
(무료, 교회 구글 계정만 있으면 되고, 결과를 사무실에서 시트로 바로 확인)

### (다) 설교 영상 연결
`sermon.youtube` 에 주소를 넣으면 주보에서 바로 설교 영상으로 갑니다.
챌린지의 "추가 묵상질문 유튜브 영상"도 같은 방식으로 붙일 수 있습니다.

### (라) 행사 페이지
수련회·나들이 때는 좌석표·타임테이블·장소 길찾기·사진첩을 붙인 행사 페이지를
따로 만들어 주보에서 링크로 연결하는 방식이 깔끔합니다.

## 파일 구조

```
교회주보앱/
├─ 0_미리보기.bat             올리기 전 확인
├─ 1_주보변환.bat             워드 파일을 여기 끌어다 놓기
├─ 2_올리기.bat               깃허브에 올리기
├─ index.html                 앱 전체 (화면 + 동작)
├─ data/
│  ├─ bulletins.js            ← 매주 바뀌는 파일
│  ├─ hymns.js                찬송가 번호 → 제목 (쓸 때만)
│  └─ bible/                  개역한글 66권 (책별 파일) + _index.js
├─ assets/                    교회 로고 · 배너 · 아이콘 · 사진
├─ tools/
│  ├─ docx_read.py            워드에서 글자만 뽑기
│  ├─ docx_to_bulletin.py     워드 → 주보 데이터 변환
│  └─ build_bible.py          성경 데이터 다시 만들기 (한 번 해두면 끝)
├─ docs/
│  └─ 깃허브-올리는법.md       처음 올리기 · 매주 올리기
├─ manifest.webmanifest       홈 화면 추가용
├─ sw.js                      오프라인 캐시 (주보 데이터는 항상 새로 받음)
└─ README.md                  이 문서
```

미리보기는 `0_미리보기.bat`, 또는 `python -m http.server 8792 --directory .` 후 `http://localhost:8792`
