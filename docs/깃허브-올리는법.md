# 깃허브에 올리는 법

주보 앱은 **깃허브 페이지(GitHub Pages)** 라는 무료 웹 호스팅에 올립니다.
돈이 안 들고, 서버를 따로 관리할 필요가 없고, 주소가 안 바뀝니다.

- **처음 한 번** — 저장소를 만들고 웹에 공개하는 설정 (아래 1번, 5분)
- **매주** — 워드 받아서 두 번 더블클릭 (아래 2번, 2분)

---

## 1. 처음 한 번만 하는 것

### 준비 — 깃허브 로그인 확인

명령 프롬프트(검은 창)를 열고:

```bash
gh auth status
```

`✓ Logged in to github.com account ...` 가 나오면 됩니다.
안 나오면 `gh auth login` → 화살표로 **GitHub.com → HTTPS → Y → Login with a web browser**
를 고르고, 화면에 나온 8자리 코드를 브라우저에 넣으면 끝입니다.

### 1-1. 저장소 만들고 올리기

주보앱 폴더에서 (주소창에 `cmd` 치고 엔터 치면 그 폴더에서 열립니다):

```bash
gh repo create dongtan-rejoice-bulletin --public --source . --push
```

- `dongtan-rejoice-bulletin` → 저장소 이름입니다. 나중에 주소가 됩니다.
- `--public` → 누구나 주소를 알면 볼 수 있게 (교인들이 로그인 없이 봐야 하니 필요합니다)
- `--source .` → 지금 이 폴더를 올린다
- `--push` → 만들고 바로 올린다

### 1-2. 웹페이지로 켜기

```bash
gh api -X POST repos/vulkanuslee-afk/dongtan-rejoice-bulletin/pages -f "source[branch]=main" -f "source[path]=/"
```

2~3분 뒤 이 주소가 열립니다:

```
https://vulkanuslee-afk.github.io/dongtan-rejoice-bulletin/
```

이 주소를 교회 단톡방에 올리면 끝입니다. 교인들은 눌러서 보고,
**홈 화면에 추가**하면 앱처럼 아이콘이 생깁니다.

> 명령어가 부담스러우면 브라우저로도 됩니다 — [아래 4번](#4-명령어-없이-브라우저로만-하기)

## 2. 매주 하는 것 (주보 담당자가 워드를 주면)

### 더블클릭 두 번

1. 받은 **워드 파일(.docx)** 을 `1_주보변환.bat` **아이콘 위로 끌어다 놓기**
   → 날짜·호수·설교·예배순서·소식을 알아서 뽑아 넣고, 미리보기가 열립니다
2. 내용 확인 → `2_올리기.bat` **더블클릭** → 메모 적고 엔터

2~3분 뒤 교인들 폰에서 새 주보가 보입니다. 끝입니다.

### 변환이 다 못 잡았을 때

변환 결과에 `TODO: 확인` 이라고 뜨면, 그 항목만 못 찾은 것입니다.
`data\bulletins.js` 를 메모장으로 열어 `TODO: 확인` 을 찾아 고치면 됩니다.
(워드 양식이 주마다 조금씩 달라서 그렇습니다. 틀린 걸 지어내지 않고
**못 찾았다고 알려주는 쪽**으로 만들어 뒀습니다)

고치고 나서 `0_미리보기.bat` 으로 다시 보고, `2_올리기.bat` 하면 됩니다.

### 워드가 .doc 일 때

옛날 형식(.doc)은 못 읽습니다. 워드에서 **다른 이름으로 저장 → .docx** 로
한 번 바꿔서 주시면 됩니다.

## 3. 명령어로 직접 할 때

배치 파일 안에서 도는 건 이 세 줄입니다.

```bash
git add -A
git commit -m "11월 15일 46호"
git push
```

- `git add -A` — 바뀐 파일 전부 담기
- `git commit -m "메모"` — 메모 붙여서 기록 남기기
- `git push` — 깃허브로 보내기

올린 기록을 보려면 `git log --oneline`, 지금 뭐가 바뀌었는지 보려면 `git status`.

## 4. 명령어 없이 브라우저로만 하기

1. github.com 로그인 → 오른쪽 위 **＋ → New repository**
2. Repository name 에 `dongtan-rejoice-bulletin`, **Public** 선택 → Create
3. 만들어진 화면에서 **uploading an existing file** 클릭
4. 주보앱 폴더의 파일을 **전부 끌어다 놓기** → Commit changes
5. 위 탭의 **Settings → Pages** → Source 를 **Deploy from a branch**,
   Branch 를 **main / (root)** 으로 두고 **Save**
6. 2~3분 뒤 같은 화면에 주소가 뜹니다

매주 바꿀 때는 그 저장소에서 `data/bulletins.js` 파일을 클릭 →
연필 아이콘(Edit) → 내용 고치고 → **Commit changes** 하면 바로 반영됩니다.

## 5. 자주 막히는 것

**새 주보가 안 보여요**
주보 내용은 열 때마다 새로 받아오게 되어 있어서 보통은 바로 바뀝니다.
그래도 안 바뀌면 깃허브 저장소의 **Actions** 탭에서 초록색 체크가 떴는지 보세요.
아직 돌고 있으면 1~3분 더 기다리면 됩니다. 빨간 X 면 눌러서 이유를 볼 수 있습니다.

**`git push` 할 때 로그인하라고 나와요**
`gh auth login` 을 다시 한 번 해 주세요.

**잘못 올렸어요**
바로 전으로 되돌리려면 `git revert HEAD` 하고 `git push`.
주보 내용만 되돌리려면 `data\bulletins.backup.js` 가 바로 직전 백업입니다.

**페이지를 내리고 싶어요**
깃허브 저장소 → Settings → Pages → Source 를 **None** 으로.
또는 Settings 맨 아래 **Change visibility → Private** 로 바꾸면 즉시 안 열립니다.

`https://vulkanuslee-afk.github.io/dongtan-rejoice-bulletin/` 이 길다면:

- 저장소 이름을 `jubo` 처럼 짧게 (Settings → Repository name → Rename)
- 또는 교회 도메인 `rejoicech.kr` 의 하위 주소(예: `jubo.rejoicech.kr`)를 연결
  (홈페이지 관리하는 곳에서 CNAME 추가 + 저장소 Settings → Pages → Custom domain)
